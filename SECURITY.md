# Security Policy

## Supported versions

DSH Launcher is currently a developer preview. Security fixes are applied to the latest code on `main` and the newest published release only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's **Security → Report a vulnerability** page to submit a private report:

https://github.com/minorsnownight/dsh-launcher/security/advisories/new

Include the affected version, operating system, reproduction steps, expected impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

Do not include credentials, tokens, personal files, or other sensitive data in a report.
